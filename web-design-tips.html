Better Web Design

Five things to do and five things to avoid when building a website. This page is styled with a separate CSS file.

5 things you should do

  • Use clear, descriptive headings.
  • Organize information into easy-to-follow sections.
  • Choose readable fonts and sufficient contrast.
  • Add alternative text to important images.
  • Test navigation and layout on phones and computers.

5 things to avoid

  • Do not overcrowd pages with too much content.
  • Do not use tiny text that is hard to read.
  • Do not rely on confusing or broken links.
  • Do not use distracting animations unnecessarily.
  • Do not use inconsistent colors and layouts on every page.

Why CSS matters

CSS stands for Cascading Style Sheets. The style.css file controls this website's colors, fonts, headings, cards, spacing, and mobile layout. Keeping design rules in a separate file makes the HTML simpler to read and edit.
